# Kaynaklar

## Hazır veri setleri

- **PlantVillage** (38 sınıf, 50.000+ etiketli fotoğraf) — transfer learning temeli
  https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset
- **New Plant Diseases Dataset** (sağlıklı + hasta yapraklar)
  https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset
- **PlantDoc** (gerçek tarla fotoğrafları, daha zorlu)
  https://www.academia.edu/89404399/PlantDoc
- **Olive Leaves Disease** (4.138 zeytin yaprağı, 4 sınıf)
  https://www.researchgate.net/publication/382147728_Olive_Leaves_Disease_Detection_and_Classification_using_Deep_Learning
